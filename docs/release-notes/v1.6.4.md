**Date:** 2026-08-04

## Security

First-party hardening from the DIY security audit (all priorities):

| Issue | Fix |
|-------|-----|
| Path escape via tool args (`../`, absolute) | `resolveUnderRoot` + realpath confinement on all reads/lists |
| Symlink escape | realpath of target/ancestors must stay under project root |
| ReDoS on `pattern` / `name_pattern` | escaped literal + safe `*` wildcards, max 200 chars |
| Hub path disclosure | redact full paths unless `UNITY_MCP_ALLOW_HUB_PATHS=1` |
| Huge markdown returns | 200KB truncate for docs/skills/agent/changelog |

No product behavior change for legitimate in-project paths.
