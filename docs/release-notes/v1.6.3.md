# v1.6.3

**Date:** 2026-08-04

## Security

Reverts the Socket Registry experiment from **1.6.2**.

### Why

Applying `@socketregistry/*` overrides cleared “Socket optimized override available” alerts, but Socket then scored those same packages as **Unpopular package** (low adoption), which dropped **Quality** and **Supply Chain** scores. Reachability also marked them unused.

### Kept

All **CVE** patches from 1.6.1 (`hono`, `@hono/node-server`, `fast-uri`, `path-to-regexp`, `express-rate-limit`, `body-parser`, `qs`, `ip-address`, `ajv`, `esbuild`, MCP SDK 1.30).

### Expectation after rescan

- Vulnerability: **100**
- Quality: back near **100**
- Remaining “optimized override available” alerts are Socket product suggestions, not CVEs — safe to **Monitor** / ignore in policy
